# NullWire (Standard Edition)
**Simple, Ultra-Low Latency Wireless PC Audio to Android Phone**

NullWire Standard is the clean, free, single-purpose edition designed for instantaneous, low-latency audio transmission without extra menus or setup steps.

---

## 🚀 Quick Start Guide

### Option A: Install via Setup Wizard (Recommended)
1. Run **`NullWire_Setup.exe`**.
2. Follow the wizard steps to install desktop and start menu shortcuts.
3. Launch **NullWire** from your desktop.

### Option B: Portable Standalone Executable
* You can directly run **`NullWire.exe`** without installing anything!

### 📱 Android Setup
1. Install and launch **`NullWire.apk`** on your Android phone.
2. Ensure your phone and PC are connected to the same Wi-Fi network.
3. Tap **`▶ Listen (Connect Audio)`** (auto-starts on launch).

### 💻 Connecting PC to Phone
1. On your PC, click **`🔍 Auto-Pair`** (it detects your phone automatically over the local network).
2. Click **`▶ START AUDIO STREAM`**.
3. Enjoy crystal-clear, bit-perfect PC sound in your phone's headphones with **<2.67ms latency**!

---

## 📦 Binaries Included

* **`NullWire_Setup.exe`**: Self-contained Setup Wizard with embedded binaries & uninstaller.
* **`NullWire.exe`**: Lightweight standalone Windows streamer (Zero install needed).
* **`NullWire_Uninstall.exe`**: Dedicated clean graphical uninstaller.
* **`NullWire.apk`**: Direct MMAP low-latency Android receiver app.
